# ことばの本来

「役不足」「気が置けない」「足をすくわれる」など、本来とちがう意味や言い方で使われやすい言葉を、意味・使い方・言い方の3つで確かめる1日5問の学習ゲームです。正解すると、文化庁の調査で本来の意味を選んだ人が何%だったかが出ます。

遊ぶ: <https://satou-aaaaa.github.io/kotoba-honrai/>

## 遊び方

- 今日の5問（だれでも同じ・1日1回）：本来の意味は？ → 本来の言い方は？ → 本来の意味で使っているのは？ → 本来の意味は？ → 本来の言い方は？
- 上級（本来の意味を選ぶ人が3割に届かない言葉から3問・ヒントなし）・練習（何度でも）・とことん（まちがえても続き、「ここで降りる」まで）・おさらい（まちがえた問題）
- 言葉帳（51の言葉の本来の意味・例文・調査の数字）・実績・カレンダー（取りこぼした過去7日をあとから）
- 時間制限なし。記録は遊ぶ人のブラウザ（localStorage）だけに置き、外へ送りません。

## 中身の出どころ

言葉・本来の意味・ほかの意味・割合は、文化庁「国語に関する世論調査」（平成18・19年度、令和元〜7年度）から取りました（一覧は `data.js` の `SRC` と、ゲームの「このゲームについて」）。問題を出す人物と例文は作り話です。

- 文化庁は「辞書等で主に本来の意味（言い方）とされてきたもの」を示しています。ゲームも「本来の意味」と書き、ほかの使い方を「まちがい」と決めつけません。
- 令和2年度から調査のしかたが面接から郵送に変わりました。数字には年度を添えています。
